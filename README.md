# Factorial Calculator

A simple **Factorial Calculator** built using Python.
This beginner-friendly project calculates 
the factorial of a given non-negative number.

## Features

- Accepts a number from the user
- Calculates the factorial
- Handles negative numbers
- Displays the result clearly
- Simple and beginner-friendly

## Technologies Used

- Python
- `for` loop
- `if-else` statements
- `range()`
- User input
- Arithmetic operators

## Concepts Learned

- Variables
- Loops
- Conditional statements
- User input
- Type conversion
- Multiplication
- Factorial calculation
